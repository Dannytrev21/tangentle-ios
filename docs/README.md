# Tangentle iOS

ADHD-friendly executive function assistant for iOS.

## Features
- Task management with subtasks and dependencies
- Project and goal tracking
- Strategy coaching with scoring
- Focus modes for context switching
- Habit and routine tracking

## Requirements
- iOS 17.0+
- Xcode 15.0+

## Architecture
- SwiftUI + UIKit (for gestures)
- Core Data with CloudKit preparation
- MVVM + Repository pattern
- Manual dependency injection

## Getting Started
1. Open `Tangentle.xcodeproj`
2. Select iOS 17+ simulator
3. Build and run (Cmd+R)

## Project Structure
```
Tangentle/
├── App/           # App lifecycle
├── Core/          # Business logic
├── Features/      # Feature modules
├── UI/            # Reusable components
├── Data/          # Core Data
└── Resources/     # Assets
```

## Commands
Run `/help` in Claude Code to see available commands.
